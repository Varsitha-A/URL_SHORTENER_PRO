🚀 URL Shortener Pro is a full-stack web application built to simplify long URLs into short, shareable links with powerful analytics support. It provides a smooth and modern SaaS-style experience with a secure authentication system and an interactive dashboard.
Youtube video Link : https://youtu.be/y1wiggKoRJs?si=oKdMzT6ykZrTKfxB
✨ Key Features:

🔗 Shorten long URLs instantly with unique short codes
✏️ Create custom aliases for personalized links
📊 Real-time analytics dashboard with click tracking
📱 Device tracking (Mobile / Desktop / Tablet users)
🌍 Country-based traffic analysis using IP geolocation
📈 Visual insights using charts and analytics graphs
📷 Auto-generated QR codes for every short link
🔐 Secure login & registration using JWT authentication
👤 User profile management with editable details
🎨 Modern dark-themed SaaS UI for better UX

🛠️ Tech Stack:

⚛️ React.js (Frontend)
🎨 Tailwind CSS (UI Styling)
🟢 Node.js + Express.js (Backend)
🍃 MongoDB (Database)
🔐 JWT Authentication + bcrypt (Security)
📡 IP Geolocation API + User-Agent Parser
📷 QR Code Generator API

💡 Project Highlights:

📌 Full-stack MERN architecture
📌 Real-time analytics system like Bitly
📌 Scalable and modular backend design
📌 Responsive and professional UI design
📌 Production-ready project structure
